# Sounds

Drop CC0-licensed audio files here:

- `gavel.mp3` — single sharp gavel hit, played on verdict.
- `bell.mp3` — chime, played on each scoring stamp.
- `courtroom.mp3` — looping ambient murmur (~3 sec, fades cleanly).

The frontend looks for these at `/sounds/*`. If they are missing, the
audio simply does not play — the trial still works.

Suggested sources: freesound.org (CC0), Pixabay Music, Mixkit.
